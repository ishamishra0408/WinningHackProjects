# Top 3 Winners by Event

Pulled directly from each gallery / winners writeup listed in [events-by-topic.md](events-by-topic.md).

**On the link column.** The link here is the winning team's Cerebral Valley profile. That was
adopted on the belief that CV has no per-project permalink — **which is wrong, and the correction
matters**: each gallery embeds a schema.org `ItemList` carrying a per-project URL (`?project=N`)
and the project's GitHub repo. See [winner-audits.md](winner-audits.md) for the harvest; 1,060 of
1,092 projects across 12 galleries carry a repo link. This column has not been rewritten yet. The four non-CV writeups do have real project links
(GitHub repos, submission posts) and those are used instead.

Where the team name and the product name differ, both are given as `Team — Product`.

## 6 · Graph Engineering

### Hack the Video Agent Context Graph — Neo4j · Jul 30 2026 — 151 builders, 37 projects
Four required tools, so every project used all four: AWS Strands, OpenAI, TwelveLabs, Neo4j.
Organizer's framing: the question wasn't *whether* winners used a graph but *how well*.
Three of the top seven built on the [starter repo](https://github.com/jpadams/video-context-graph).

| Place | Project | What it is | Link |
|-------|---------|------------|------|
| 🥇 1st | MealPrep Video Context Graph | Meal-prep videos → planning graph: every ingredient with quantity, technique, temperature, macro, allergen at segment level. Answers in timecodes because each is a `(:Segment)-[:APPLIES]->(:Technique)` edge. Extraction refuses to guess — no on-screen nutrition panel means it writes 0, not an LLM estimate. | [repo](https://github.com/roopadevihosur-07/MealPrep_VideoContexGraph) |
| 🥈 2nd | Rehearsal | "Video is evidence" → "video is coaching." Record a practice talk; it transcribes live, scores seven delivery dimensions, and returns a timestamped debrief where every weakness links to the exact minute of a world-class talk that demonstrates the fix. Best demo of the day — he gave a talk about giving talks, stopped, and the screen already had the scores and the fix clips. | [repo](https://github.com/altonalexander/rehearsal) |
| 🥉 3rd | ZooVision | Overnight animal-welfare monitoring for zoo keepers: fixed-camera footage in, a Neo4j graph per enclosure and a timestamped activity timeline out, with a morning review-and-handoff workflow. Deliberately the most conservative system — the README opens by stating what it is *not*: not a medical device, no diagnosis, no actuators. Most finished thing in the room. | [repo](https://github.com/rishabhcli/ZooVision) |

Full writeup: [Neo4j blog](https://neo4j.com/blog/developer/one-starter-repo-three-winners-neo4j-at-hack-the-video-agent-context-graph/)
